# 360° 地面音波扩散效果 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在当前 Cinema 4D 文档中制作四圈黄绿色、可循环向外传播的 360° 地面音波。

**Architecture:** 使用四个参数化圆盘对象组成环带，通过动画化内部半径和外部半径形成错峰向外传播；四个对象共享一个 Redshift 自发光节点材质。所有场景写入通过 Cinema 4D MCP 完成，几何、材质、关键帧和渲染分别验证。

**Tech Stack:** Cinema 4D 2025.3.2、Cinema 4D MCP、Redshift 节点材质、C4D 参数关键帧。

## Global Constraints

- 文档：`未标题 2`。
- 项目帧率：25 fps。
- 动画范围：0–75 帧。
- 当前渲染器：Redshift。
- 波纹形态：360° 完整圆环。
- 同屏保持 4 圈，依次向外扩散。
- 保留现有时间范围、渲染器和镜头设置。
- 圆环外半径范围：18–180 cm。
- 圆环宽度范围：14–3 cm。
- 圆环高度：Y=0.5 cm。
- 关键帧插值：线性。
- 不保存到磁盘，除非用户另行提供保存路径。

## 变更结构

- 修改实时 Cinema 4D 文档 `未标题 2`：将 `/圆盘` 重命名并作为第一圈使用。
- 创建对象层级：`/音波扩散_控制/音波_01` 至 `音波_04`。
- 创建材质：`音波_黄绿_RS`。
- 不修改仓库源代码。
