# Cinema 4D 2025 MCP Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a safe, installable MCP foundation whose live smoke suite can prove compatibility with Cinema 4D 2025.3.2.

**Architecture:** Retain the upstream TypeScript STDIO MCP server and modular Cinema 4D Python bridge. Add a pure compatibility policy, a runtime capability command, a dry-run-first Windows installer, and a non-skippable foundation smoke mode before enabling advanced 2025 capability packs.

**Tech Stack:** TypeScript 6, Node.js 24, MCP TypeScript SDK, Zod 4, Vitest 4, Cinema 4D Python 3.11 API, PowerShell-compatible Node installer.

- First verified DCC target: Cinema 4D 2025.3.2 on Windows x64.
- Bind to `127.0.0.1` by default; remote access stays opt-in.
- `exec_python` stays disabled by default.
- Installation writes only to the current user's Cinema 4D preferences and defaults to dry-run.
- Live tests use a new temporary document and save only a copy.
- Preserve the upstream MIT license and copyright.
