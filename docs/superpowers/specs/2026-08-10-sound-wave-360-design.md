# 360° 地面音波扩散效果设计

## 目标

在当前 Cinema 4D 文档“未标题 2”中，以已选中的圆盘中心为声源，制作类似参考图的地面音波扩散效果。效果为 360° 完整圆环，在 0–75 帧内持续向外传播并可循环播放。

## 已确认约束

- Cinema 4D 版本：2025.3.2。
- 项目帧率：25 fps。
- 动画范围：0–75 帧。
- 当前渲染器：Redshift。
- 波纹形态：360° 完整圆环。
- 同屏保持 4 圈，依次向外扩散。
- 保留现有时间范围、渲染器和镜头设置。

## 实现方案

采用四个扁平圆环对象组成几何波纹。将当前圆盘改为第一圈并复制三份，统一放入名为“音波扩散\_控制”的空对象下。每圈使用圆盘对象的内部半径和外部半径形成环带，不转为可编辑模型，以便继续调整。

四个圆环共享一个黄绿色 Redshift 自发光材质，初始发光强度设为 4。每个圆环放在 Y=0.5 cm，降低与后续地面重叠时的闪烁风险。

## 动画

- 四圈采用 19 帧的相位间隔，播放时保持连续的波纹层次。
- 每圈从 18 cm 外半径扩张到 180 cm。
- 扩张过程中将环带宽度从 14 cm 减小到 3 cm，用几何变细模拟远端衰减。
- 各圆环在不同帧到达最大半径并重置到中心。
- 第 0 帧与第 75 帧的整体波纹分布一致，循环切换时不出现整体停顿。
- 关键帧使用线性插值，保持传播速度稳定。

## 场景结构

```text
音波扩散_控制
├─ 音波_01
├─ 音波_02
├─ 音波_03
└─ 音波_04

材质：音波_黄绿_RS
```

## 验证标准

- 顶视图能看到四个同心的完整圆环。
- 第 0、19、38、57、75 帧均能看到波纹由内向外错峰分布。
- 连续播放时，波纹传播方向始终向外。
- 第 75 帧切回第 0 帧时整体分布连续。
- 圆环贴近地面但不与 Y=0 共面。
- Redshift 材质表现为清晰的黄绿色自发光，不依赖场景灯光才能辨认。
- 圆盘以外的现有镜头、渲染设置和时间范围不被修改。
