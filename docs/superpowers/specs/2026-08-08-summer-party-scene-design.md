# 夏日派对定帧场景还原设计

## 目标

在 Cinema 4D 2025.3.2 中新建独立文档，用 Redshift 还原参考图的夏日派对场景。交付目标是一张约 2.37:1 的超宽定帧画面，优先匹配构图、主体比例、色彩和空间层次，不追求镜头外结构或小装饰的完整建模。

## 已确认决策

- 采用 2.5D 分层搭建：近景主体为可编辑三维模型，中远景使用简化模型和剪影式装饰。
- 使用 Redshift 渲染。
- 默认输出 1280×540。
- 保留 `BOOM`、`CFM SUMMER PARTY` 等主要可见文字。
- 新建并保存独立 C4D 文档，不修改当前含有 `Male Base` 的未保存文档。

## 镜头与构图

- 摄像机采用正面轻微低机位和温和广角，保持边缘夸张但避免明显鱼眼变形。
- 前景占据画面下方约 40%：左侧救生圈与碰杯啤酒，中央沙滩球、音符和笑脸球，右侧 `BOOM` 文字及冲浪板。
- 中景以中央 DJ 舞台和音响墙为视觉锚点，两侧安排吉他、彩色台阶和派对装饰。
- 背景由蓝天、云层、棕榈树、集装箱建筑及顶部霓虹框架组成，利用尺寸递减和层间距形成纵深。

## 场景结构

场景根节点分为以下五组：

1. `SET_FRAME`：上下横梁、侧柱、地台和背景围合结构。
2. `FG_HERO_PROPS`：救生圈、啤酒杯与泡沫、沙滩球、音符、笑脸球、`BOOM` 文字、冲浪板。
3. `MID_STAGE`：DJ 台、音响、星形标志、台阶、吉他及少量装饰。
4. `BG_TROPICAL`：棕榈树、云层、建筑块、遮阳伞和天空背景。
5. `LIGHTS_CAM`：主摄像机、主光、轮廓光、环境光和必要的发光装饰。

近景对象使用圆角、倒角和适度细分保证轮廓质量；中远景限制几何复杂度，仅建立当前镜头可见的正面和侧面。

## 材质与灯光

- 主材质为高饱和塑料，使用较高粗糙度和柔和高光，避免金属般尖锐反射。
- 啤酒杯采用透明玻璃、琥珀色液体和独立泡沫几何体；泡沫由不同尺寸球体聚合形成。
- 救生圈、沙滩球和冲浪板使用粉、青、黄、绿的糖果色分区。
- 文字和舞台标志使用粉紫、青蓝和黄色发光材质，以适量 Bloom 强化霓虹感。
- 主光为偏暖的大面积柔光；青蓝环境光统一天空氛围；粉紫轮廓光分离前景与背景。

## 制作顺序

1. 创建新文档、渲染设置和摄像机，先用灰模锁定画幅与主体占比。
2. 完成近景标志性道具和立体文字，确保剪影与参考图一致。
3. 补齐中央舞台、两侧建筑及热带背景。
4. 创建 Redshift 材质和灯光，先统一大色块，再调整透明、发光和反射细节。
5. 进行低采样预览，对比参考图校准位置、尺度、颜色和遮挡。
6. 保存 C4D 工程并输出最终预览图。

## 异常与回退

- 若某个复杂装饰无法通过现有 C4D MCP 稳定生成，则改为更简单的几何剪影，不影响主构图。
- 若 Redshift 节点材质创建失败，则先以兼容材质完成灰模和构图，再单独修复对应材质，不中断其他对象搭建。
- 所有修改只发生在新文档中；当前两个未保存文档保持原状。

## 验收标准

- 输出分辨率为 1280×540，主体无意外裁切。
- 左、中、右三组前景主体的位置和面积关系与参考图接近。
- 中央舞台位于视觉中心，背景具有明确的热带派对语义和纵深。
- 整体呈现青蓝、粉紫、亮黄为主的高饱和糖果色，并具有柔和塑料高光和霓虹辉光。
- C4D 工程可重新打开，摄像机、对象分组、主要材质和灯光均可编辑。
