# 0.5.0 动画曲线开发与验证记录

## 状态与边界

本轮补充中文首页和四个 F-Curve 接口。源码版本为 0.5.0，注册 83 个工具，默认开放 82 个；工具数量不是“完整控制所有 C4D 功能”的保证。

**0.5.0 尚未安装到运行中的 Cinema 4D，也尚未通过实机专项验收。** 本轮只对 C4D 执行了连接与工程状态读取，没有创建工程、改动动画、启动渲染、替换运行中的插件或重启 C4D。先前 [0.4.0 的实机记录](./2026-09-06-workflow-validation.md) 不能作为本轮新功能已实测的证据。

## 新增接口

| 工具                      | 范围                                                                           |
| ------------------------- | ------------------------------------------------------------------------------ |
| `get_fcurve`              | 读取现有 REAL 曲线、准确关键帧时间、有效切线及外推；可采样子帧，不移动工程时间 |
| `edit_fcurve_keys`        | 按当前快照索引修改数值、插值和自动/手动切线                                    |
| `transform_fcurve`        | 对选中或全部关键帧进行正向时间缩放、偏移及数值变换，预检与其他键的时间碰撞     |
| `set_track_extrapolation` | 分别设置前后外推：关闭、恒定、延伸、重复、偏移重复、往复                       |

每次调用都需精确活动工程名、实体句柄以及完整参数路径或旧选择器。单轨道上限 1000 个键，采样最多 300 个时间点。键索引不是稳定 ID：手动编辑或其他调用可能使它过时；变换后必须重新读取。

自动切线保留自动模式，由 C4D 重新计算；不能承诺部分关键帧变换后整条曲线形状不变。整数/布尔轨道、耦合 XYZ、四元数、时间映射、动画层、运动剪辑、骨骼蒙皮、约束烘焙和点级动画不在本轮曲线接口范围内。

## 子帧回归

旧 `get_keyframes` / `delete_keyframe` 使用 `GetFrame(fps)` 取整。新增 0.25 和 0.75 帧回归先复现 `[0, 1]` 的错误读取，再改为准确时间读取与 `BaseTime` 比较。整数帧删除和范围筛选不再把相邻子帧取整后误删；旧 `set_keyframe.frame` 仍保持整数输入。

## 验证方式

2026-09-06 本机离线最终结果：

- `python -m unittest discover -s tests/python`：160 项通过，其中新增 F-Curve 专项 19 项；旧动画子帧保护另增 1 项。
- `npm test`：126 项通过，13 个文件；新增曲线接口校验 15 项。
- `npm run check`：类型检查、lint、格式、Python Ruff、构建及生成工具文档一致性全部通过。
- 未执行任何 `test:live:*` 命令。本轮 Python 和 TypeScript 通过数都是离线测试数。

- TypeScript 校验工具注册、完整/旧参数路径、请求转发、列表上限、有限数值、重复索引、切线方向、模式冲突及未知字段拒绝。
- Python 使用假 C4D 运行时验证前置拒绝、写入与撤销调用、切线变换及错误路径；假运行时不能证明 C4D 实际曲线形状、原生克隆行为或循环求值正确。
- `npm test` 和 GitHub CI 只执行离线测试，不会连接 C4D。
- `tests/e2e/fcurves-2025.test.ts` 是待执行的单工程专项测试，预期检查实际 Bezier 采样、自动切线、撤销、子帧重定时、碰撞拒绝、轨道外推及工程状态恢复。它不是已通过记录。

专项命令 `npm run test:live:fcurves:2025` 要求显式测试意图、候选桥接版本 0.5.0、能力标志与正确安全门。在创建唯一临时工程前检查这些条件；原活动工程无对象或材质时提前拒绝，避免空白工程被 C4D 自动替换。测试禁用时的跳过不等于通过。

## SDK 依据

- [Maxon 2025.3 CKey](https://developers.maxon.net/docs/py/2025_3_0/modules/c4d/C4DAtom/CKey/index.html)：值与切线接口、轨道类别的适用范围。
- [Maxon 2025.3 CCurve](https://developers.maxon.net/docs/py/2025_3_0/modules/c4d/C4DAtom/GeListNode/BaseList2D/CCurve/index.html)：有效切线、关键帧操作及曲线采样。
- [Maxon 2025.3 CTrack](https://developers.maxon.net/docs/py/2025_3_0/modules/c4d/C4DAtom/GeListNode/BaseList2D/CTrack/index.html)：前后循环、曲线读取、轨道求值与耦合检查。

手动设置隐藏的原始切线数据并不代表自动/夹制后的有效切线已改变，读回与实机采样必须独立验证。使用了官方接口不等于已经覆盖时间线全部功能。
